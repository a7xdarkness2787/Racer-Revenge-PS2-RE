# Research Program

This document describes the long-term reverse-engineering program without tying the work to numbered phases.

## Target preservation and provenance
Maintain exact hashes, sizes, region/build identity, disc metadata, extracted-file manifests, tool limitations, and source provenance.

## Disc and resource inventory
Classify every directory, extension, archive family, configuration resource, movie, audio bank, pod dataset and track dataset.

## Executable architecture
Map the ELF, startup path, constructors, allocators, file I/O, resource management, object systems, subsystem boundaries, virtual dispatch, global tables and build-specific addresses.

## Resource formats
Produce reproducible specifications and inspection tools for RES, PHY, SPL, COL, PSG, PSM, PST, CAM, LSI, JUK/JUB and other retail formats.

## Vehicle systems
Recover pod definitions, geometry references, physics, control response, engine behavior, boost, heat, upgrades, damage, repair, component breakage and collision response.

## Track and world systems
Recover geometry, splines, route graph, checkpoints, progress markers, shortcuts, triggers, animated scenery, collision, water, environmental effects and cameras.

## Race logic and AI
Map race startup, grid placement, lap/checkpoint validation, position/scoring, opponent steering and pacing, combat decisions, recovery, finish logic and progression effects.

## Renderer and effects
Map DMA/GIF/VIF/VU behavior, GS state, geometry submission, texture/material handling, lighting, particles, shadows, water, screen effects and UI rendering.

## Audio, movies and front end
Document VAG playback, event configuration, jukebox/music logic, speech/announcer routing, PSS playback, menu/front-end logic and save behavior.

## Runtime validation
Use PCSX2 breakpoints, watchpoints, memory inspection, deterministic inputs, save states and frame-by-frame experiments to validate static conclusions.

## Reproducible specification and closure
Turn findings into stable format specifications, function/address maps, structure definitions, machine-readable datasets, test vectors and verification scripts.
