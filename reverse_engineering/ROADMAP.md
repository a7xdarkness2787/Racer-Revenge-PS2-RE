# Roadmap

## Phase 0 — Preserve and identify
Freeze source hashes, region, boot executable, disc metadata, and file manifests.

## Phase 1 — Disc and resource inventory
Classify every directory, extension, archive family, configuration file, movie, audio bank, pod dataset, and track dataset.

## Phase 2 — Main executable
Map the ELF, startup, global constructors, memory systems, file I/O, resource manager, object system, and major subsystem boundaries.

## Phase 3 — Resource formats
Document and independently verify RES, PST, PSG, SPL, CAM, LSI, JUK/JUB and related formats found in the retail build.

## Phase 4 — Pods and vehicle systems
Recover pod definitions, geometry references, animation, engine behavior, upgrades, damage, repair, boost, heat, collision response, and vehicle state.

## Phase 5 — Tracks and world systems
Recover track geometry, splines, zones, checkpoints, shortcuts, triggers, animated scenery, collision, water, environmental effects, and cameras.

## Phase 6 — Race logic and AI
Map race states, starting grid, lap/checkpoint validation, placement, opponent AI, rubber-banding if present, combat interactions, scoring, and finish logic.

## Phase 7 — Rendering
Map DMA/GIF/VIF/VU behavior, GS state, geometry submission, texture handling, lighting, particles, shadows, water, screen effects, and UI rendering.

## Phase 8 — Audio and cutscenes
Document VAG playback, event configuration, jukebox/music logic, speech/announcer routing, PSS playback, and cutscene scripting.

## Phase 9 — Runtime verification
Use PCSX2 breakpoints, watchpoints, memory inspection, controlled input tests, save states, and frame-by-frame experiments to validate static conclusions.

## Phase 10 — Reproducible specification
Turn findings into stable format specs, named function maps, structure definitions, test vectors, extraction/inspection tools, and a documented compatibility target.
